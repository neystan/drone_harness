---
name: four-direction-search
description: 已按导航指令转向或移动并观察仍找不到参照物、需要扩大范围时，原地扫描前左后右四向，恢复朝向后一次联合判断。
enabled: true
mode: [sim, real]
---

先按当前导航指令或子目标执行对应动作并定向观察。已有候选时优先针对性核实；当前看不到目标不要求立即扫描，也不要求重复扫描。

激活时用 prompt 写清本次要寻找的参照物、任务要求的特征或关系，以及已有观察留下的疑点。程序先采开始朝向的前视图，再连续四次左转90°，每次完成后等待2秒；前三次采左、后、右图，第四次恢复开始朝向。程序只执行固定扫描，不判断目标身份。

扫描成功后，一次联合检查四张独立前视图；方向均相对扫描开始朝向，当前机头已恢复该朝向。结合原指令、当前子目标和实际动作核对候选；指出候选方向与依据，需要新证据时针对候选调整视角并 observe，不把发现候选等同于到达或完成子目标。

四图只供本次联合判断，随后退出搜索并恢复普通观察。扫描图不是当前位置的新深度；需要选点测距时先重新获取相应方向的普通前视观察。采图、转向失败或中断时停止本次扫描，不把部分图组当成完整四向扫描。
