name: four-direction-search
description: 已按导航指令行动并观察仍找不到当前参照物时，围绕一个关键疑点扫描前左后右四向，恢复朝向后联合比较，选定候选方向再定向核实。
enabled: true
mode: [sim, real]
---

先按当前导航指令或子目标执行对应动作并定向观察。已有候选时优先针对性核实；当前看不到目标不要求立即扫描，也不要求重复扫描。

激活时用 prompt 聚焦当前一个主要疑点，写清要寻找的参照物、任务要求的特征或关系，以及还缺什么证据。不要求一次找齐后续全部参照物。例如“比较各方向的水面候选及可见依据，区分水面与草地尽头的模糊亮带”，不同时搜集后续路灯、管道、卡车和仓库。

程序先采开始朝向的前视图，再连续四次左转90°，每次完成后等待2秒；前三次采左、后、右图，第四次恢复开始朝向。程序只执行固定扫描，不判断目标身份。

扫描成功后，一次联合比较四张独立前视图。简述各方向与本次疑点有关的可见事实，给出一个优先核实的候选方向、依据及关键缺口；没有可靠候选则如实说明。方向均相对扫描开始朝向，当前机头已恢复该朝向。

候选存疑时，优先朝该方向调整视角，再用 observe.prompt 核对关键缺口，避免沿未经验证的旧方向持续前进。证据足够则恢复普通导航，不增加固定复查轮次。联合判断共用全局 target_status/message，不把亮带、轮廓等相似线索直接当作确认，不把发现候选等同于到达或完成子目标。

四图只供本次联合判断，随后退出搜索并恢复普通观察。扫描图不是当前位置的新深度；需要选点测距时先重新获取相应方向的普通前视观察。采图、转向失败或中断时停止本次扫描，不把部分图组当成完整四向扫描。
